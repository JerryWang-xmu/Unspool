# UAT / TO / T 逐项验证目录

本目录是 `quickstart.md` 的可执行验收清单。每个 ID 都必须在
`packages/test-support/src/validation-cases.ts` 中恰好注册一次，并通过以下命令独立执行：

```bash
npm run validate:case -- --id UAT-01
npm run validate:case -- --id TO-01
npm run validate:case -- --id T01
```

- `QS-xx.y` 表示 quickstart 中对应场景及其夹具；执行器仍需完成该 ID 的独立准备、动作和断言。
- 每项证据写入 `artifacts/validation/cases/<ID>/summary.json`，包含实际命令、退出码、文件哈希、
  进程/网络观察、正控制、反控制及跳过原因。
- `PASS` 只表示该 ID 的独立预期和正反对照均通过。未执行、环境不支持或只有 UI 证据时，
  必须记录 `NOT RUN` 或 `BLOCKED`，不得以同组其他场景通过代替。
- UAT 的产品语义以 `PRD/Unspool-通用Agent与联邦式协作-PRD.md` 第 12 章为准；TO/T 是额外的
  权限、恢复和对抗预言，不替代 UAT。
