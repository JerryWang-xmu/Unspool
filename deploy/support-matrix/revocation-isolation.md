# Revocation, quarantine, and isolation

- Pause stops new work without rewriting history. Revoke prevents all future use and records a tombstone. Quarantine isolates an untrusted node from recipients and model/member/public disclosure.
- Only the local owner can unquarantine; remote nodes cannot restore themselves. Every directive carries a monotonic state revision and reason.
- Disabled or expired team experts immediately lose current sessions and historical workspace access while attribution remains intact.
- Operator epoch and attempt epoch changes are atomic. Old operators lose direct Run control but may retain discussion rights.
- Execution networks are internal. Workers cannot join the model/control network, publish host ports, or reach arbitrary Internet endpoints. Only the Runner and explicit fake-external are available.
- A consumed Permit, revoked Grant, or unknown outcome is never reused. Queued instructions remain withheld until a human selects retain/modify/delete/release.
- Stable remains usable when every Beta component is absent or disabled. Emergency disable returns all levels to `disabled` without deleting evidence.
